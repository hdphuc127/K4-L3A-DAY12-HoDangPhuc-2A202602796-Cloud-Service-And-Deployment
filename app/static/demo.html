🧪 Day 12 Production Agent — Demo UI

Bấm từng nút theo thứ tự để xem hành vi production của service (health, auth, state, rate limit, cost guard).

1. Liveness / Readiness

/health không đụng Redis; /ready có ping Redis.







  
2. Bảo mật API key

  
Không key → 401. So khớp key dùng compare_digest (chống timing attack).

  
  

  
  
  






  
3. State qua Redis (history_length)

  
Gọi 2 lần cùng user_id — lần 2 phải có history_length > 0.

  
  
  
  






  
4. Rate limit (sliding window)

  
Bắn 15 request liên tiếp cho cùng user_id — sẽ thấy 429 xuất hiện.

  
  






  
5. Cost guard

  
Nếu MONTHLY_BUDGET_USD nhỏ, gọi liên tục sẽ chạm 402 trước khi tốn thêm tiền LLM.
